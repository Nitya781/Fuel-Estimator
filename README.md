&#x20;Fuel Estimator for Aircraft



A Python-based aircraft fuel estimation system that uses FlightGear flight telemetry to monitor fuel consumption and estimate flight performance.



&#x20;Features

\- Real-time flight telemetry through UDP communication.

\- Fuel flow and fuel remaining estimation.

\- Flight endurance and operational range estimation.

\- Fuel reserve and low-fuel monitoring.

\- Dashboard for displaying flight and fuel information.



&#x20;Technologies Used

\- Python

\- FlightGear

\- UDP communication

\- HTML, CSS, and JavaScript



&#x20;Project Structure

\- `Source Code/` – Application source code and modules.

\- `Documentation/` – Project report and presentation.

\- `Results/` – Screenshots of project outputs.



&#x20;How It Works

The system receives flight telemetry from FlightGear, processes flight data, estimates fuel-related parameters, and displays the results through its dashboard.
